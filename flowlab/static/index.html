Connect a real VM lab

The repository includes four QEMU/KVM guests, an authenticated agent, capture, bounded traffic scenarios, NetEm loss, and per-connection firewall enforcement. Run the reviewed administrator setup in lab/README.md, then vagrant up --provider=libvirt from the lab folder.

Offline nodes are never counted as connected systems. New homogeneous, labelled captures can be trained with flowlab prepare-pcaps manifest.json using the same extractor as live inference.
